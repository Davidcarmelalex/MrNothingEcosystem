## III. BRAND IDENTITY

### The Naming System
```
PARENT ECOSYSTEM:   M&R&Nothing
SPOKEN:             "M and R and Nothing"
ECOSYSTEM TAG:      MRN° (the degree mark = infinite)
TRIBUTE LINE:       "A tribute. By David Carmel Alex."

STREETWEAR BRAND:   MR//NOTHING
STYLING:            Always written as MR//NOTHING — caps, double slash
THE //:             Rendered in gold. Always. It's the signal cut.
LOGO MARK:          MR//NOTHING  (// in gold #B8860B)
TAG LINE:           "Built from nothing. Worn for someone."
```

### The // Rule
The double slash in **MR//NOTHING** is the signature mark of the streetwear line.
- It reads like a file path — technical, precise, inevitable
- It reads like a transmission cut — signal through silence
- It reads like a division — before and after. Nothing and everything.
- The `//` is **always in gold** when rendered in colour
- In print/embroidery: `//` in a contrasting thread or deboss
